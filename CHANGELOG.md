# Changelog

## [v0.1.0] - 2026-08-14

### Added

- Decentralized Fossil forge core (`forge.lua`) with repo init and sync
- P2P networking layer (`forge-net.lua`) with UDP discovery and TCP gossip
- CLI commands: `init`, `startnet`, `peers`, `announce`, `gossip`, `sync`
- Unit tests for the networking logic (`tests/test_net.lua`)
